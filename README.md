# 🤖 LangGraph + MCP + Chatbot

A stateful AI chatbot built with:

- **LangGraph** – agent orchestration & memory  
- **Groq ** – fast inference  
- **MCP Tools**  
  - Local Maths MCP server  
  - FastMCP expense server  (remote server ) deployed on fastmcp cloud 
- **SQLite** – persistent multi-thread chat  
- **Streamlit** – interactive UI  
---

## ✨ Features

- 💬 Multi-thread conversations  
- 🧮 Math operations via MCP  
- 💸 Add / list / summarize expenses  
- 🌐 Web search (DuckDuckGo)  
- 📈 Stock price lookup  
- 🧠 Persistent memory across sessions
